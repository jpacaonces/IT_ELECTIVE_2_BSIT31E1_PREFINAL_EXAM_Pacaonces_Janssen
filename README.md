Project Description
This project is an ASP.NET Core MVC application created for the IT Elective 2 – Web System and Technologies Prefinal Examination.

The application displays the 20 examination questions together with my selected answers.

Technologies Used
C#
ASP.NET Core MVC
HTML
CSS
Bootstrap
Visual Studio 2022
GitHub
Features
Displays all 20 examination questions
Displays the selected answer for each question
Uses the MVC architecture
Responsive and simple user interface
No database required
MVC Structure
Model
The Question model contains the question number, question text, and answer.

Controller
The ExamController contains the 20 questions and sends them to the View.

View
The Index.cshtml file displays the questions and answers in a clean card layout.
